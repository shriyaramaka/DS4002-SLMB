# Charlottesville project outputs

This folder collects the existing dataset-build and EDA outputs from the October 19 project package. The underlying data snapshot was downloaded October 9, 2026. No model fitting was performed to create this collection; SARIMAX forecasts, model scores, and residual diagnostics are not included.

## Dataset_Tables

- cville_crash_incidents.csv: 5,432 unique reported Charlottesville city crashes, 2017 through July 2026.
- cville_weather_daily.csv: 3,530 days of ERA5 weather near Charlottesville.
- cville_daily_crashes_weather.csv: main joined study table, 3,287 days in 2017–2025, totaling 5,197 crashes.
- annual_crash_counts.csv: annual totals, including a flagged partial 2026.
- source_codebook.csv: original crash API coded-value definitions.

These tables are generated by Scripts/build_dataset.py. Frozen copies are also stored in Data/ because they serve as inputs to the EDA and modeling scripts. The copies in Output/Dataset_Tables/ document the rebuilt results; they do not automatically replace the frozen inputs in Data/. Update the Data/ copies deliberately when adopting a new dataset version.

## EDA_Tables

Six summaries: overall statistics, missing values, annual counts, weekday patterns, precipitation groups, and temperature groups. These use the complete 2017–2025 study period.

## Reports

quality_report.json records source counts, missingness, date ranges, and checks. provenance.json records the original API query, retrieval times, weather request, and source hashes.

## Interpretation

The main study excludes partial 2026. Counts describe reported city crashes, not all emergencies or risk per trip. Source completeness and historical reporting delays remain unverified. Weather is regional reanalysis. Same-day weather associations are descriptive and should not be used as advance forecasting inputs. Early lag values remain missing rather than being replaced by zero.
